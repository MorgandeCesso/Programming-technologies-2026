Тестовый запрос:

В успешном тесте зафиксированы скорость **96,54 токена/с**, **71 токен** и нормальное завершение генерации по EOS-токену.

### 4.2. Qwen3-8B

Вторая модель была успешно загружена и ответила на тот же вопрос в LM Studio. Затем её работа была подтверждена через Python и локальный API.

В одном из ответов Qwen3-8B ошибочно назвала себя Qwen3.5. Это демонстрирует, что даже простые ответы могут содержать фактические неточности.

## 5. Проблемы с режимом Thinking

**Thinking** — режим, при котором модель формирует дополнительные рассуждения перед окончательным ответом.

### 5.1. Исчерпание контекста

При первом тесте Qwen3.5-4B модель использовала почти весь контекст размером 2048 токенов на рассуждения. Генерация остановилась по лимиту, а видимого итогового ответа не появилось.

### 5.2. Ограничение `max_tokens`

Аналогичная проблема наблюдалась при обращении к модели через Python с параметром:

```python
max_tokens=512
```

При таком ограничении итоговый текст ответа не отображался. Вероятная причина — расход бюджета генерации на рассуждения. После увеличения `max_tokens` ответ был получен.

### 5.3. Принятые меры

- Изменение настроек режима рассуждений в LM Studio.
- Увеличение допустимого числа генерируемых токенов.
- Добавление инструкции `/no_think` к запросам при сравнении моделей.
- Последовательная загрузка моделей в память.

**Вывод:** режим Thinking может быть полезен для сложных задач, но при небольшом контексте или лимите генерации способен увеличить задержку и помешать выводу окончательного ответа. Для объективного сравнения моделей необходимо учитывать настройки рассуждений.

## 6. Настройка локального API-сервера

В разделе **Developer** программы LM Studio запущен сервер по адресу:

```text
http://localhost:1234/v1
```

Включена настройка **Require Authentication**, создан персональный токен. Для хранения конфигурации использовался файл `.env`:

```dotenv
LM_STUDIO_API_KEY=YOUR_LOCAL_TOKEN
LM_STUDIO_BASE_URL=http://localhost:1234/v1
```

Настоящий токен в отчёт не включается. Файл `.env` исключён из Git с помощью `.gitignore`.

Для подключения использовались Python, библиотеки `openai` и `python-dotenv`:

```python
import os
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

client = OpenAI(
    base_url=os.getenv("LM_STUDIO_BASE_URL"),
    api_key=os.getenv("LM_STUDIO_API_KEY")
)
```

Получение списка моделей:

```python
models = client.models.list()

for model in models.data:
    print(model.id)
```

Сервер возвращал обе исследуемые модели:

```text
qwen/qwen3-8b
qwen3.5-4b
```

Кроме них в списке присутствовала модель `text-embedding-nomic-embed-text-v1.5`, предназначенная для эмбеддингов, а не для обычного чата.

Пример отправки запроса:

```python
response = client.chat.completions.create(
    model="qwen/qwen3-8b",
    messages=[
        {"role": "user", "content": "Объясни, что такое Python."}
    ]
)

print(response.choices[0].message.content)
```

Успешное получение ответов подтвердило работоспособность сервера, авторизации и подключения через Python.

## 7. Подготовка пяти тестовых заданий

Для обеих моделей использовались одинаковые запросы.

### Тест №1 — объяснение рекурсии

> Объясни начинающему программисту, что такое рекурсия в Python. Приведи простой пример. Ответь кратко.

**Критерии:** правильность определения, понятность объяснения, корректность примера.

### Тест №2 — функция `is_prime(n)`

> Напиши функцию Python is_prime(n), которая возвращает True, если число n простое, и False в остальных случаях. Приведи код и краткое объяснение.

**Критерии:** правильность алгоритма и обработка граничных случаев.

### Тест №3 — поиск ошибки

> Найди ошибку, объясни её и предложи исправленный код:

```python
def average(numbers):
    return sum(numbers) / len(numbers)

print(average([]))
```

**Критерии:** обнаружение `ZeroDivisionError` и корректность исправления.

### Тест №4 — извлечение данных в JSON

Исходный текст:

> Анна Иванова работает Python-разработчиком в компании ТехноСофт. Ей 25 лет. Она живёт в Казани.

Требовалось вернуть только корректный JSON с полями `name`, `age`, `city`, `company`, `position`.

Ожидаемый результат:

```json
{
  "name": "Анна Иванова",
  "age": 25,
  "city": "Казань",
  "company": "ТехноСофт",
  "position": "Python-разработчик"
}
```

**Критерии:** синтаксическая корректность JSON, наличие всех полей и точность значений.

### Тест №5 — недостаточно информации

Исходный текст:

> Компания Альфа была основана в 2015 году. Она занимается разработкой мобильных приложений. В компании работают 50 сотрудников.

Вопрос:

> Кто является генеральным директором компании?

Дополнительная инструкция: если информации недостаточно, сообщить об этом.

**Критерий:** отсутствие выдуманных фактов.

Qwen3-8B предложила вернуть `0` либо вызвать исключение. Возврат нуля предотвращает сбой, но среднее пустого набора математически не определено.

**Тест №4. JSON.** Обе модели сформировали синтаксически корректный JSON. При этом Qwen3.5-4B указала `"city": "Казань"`, а Qwen3-8B — `"city": "Казани"`. Второй вариант сохраняет падеж из исходного текста, но не является нормализованным названием города.

**Тест №5. Недостаточно информации.** Qwen3.5-4B ответила: «В предоставленном тексте нет информации о том, кто является генеральным директором компании». Qwen3-8B ответила: «Информации недостаточно». Обе модели избежали выдумывания фактов.

## 11. Выявленные ограничения

1. **Расход контекста в Thinking.** Рассуждения могут занять весь доступный контекст до появления итогового ответа.
2. **Лимит `max_tokens`.** При значении 512 токенов наблюдалось отсутствие видимого итогового ответа.
3. **Ограниченная видеопамять.** Модели запускались поочерёдно.
4. **Фактические неточности.** Qwen3-8B неверно назвала свою версию и использовала ненормализованную форму названия города.
5. **Неоднозначность исправлений кода.** Разные модели предложили различные способы обработки пустого списка.
6. **Зависимость времени от условий.** На задержку влияют режим рассуждений, длина ответа, прогрев и настройки загрузки.
7. **Небольшое число повторений.** Основные тесты выполнялись однократно для каждой модели.
