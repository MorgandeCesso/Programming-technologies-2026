Основные переменные окружения:

## 4. Методика основного эксперимента

Скрипт `experiment.py` последовательно отправляет пять одинаковых запросов каждой модели через Responses API. Каждый запрос независим: история предыдущих ответов не передается. Перед измерениями выполняется отдельный короткий запрос для прогрева; его время не включается в результаты.

Общая системная инструкция:

```text
отвечай на русском языке. следуй требованиям запроса. при работе с предоставленным текстом используй только его сведения. если информации недостаточно, сообщи об этом.
```

| Параметр | Значение для обеих моделей |
| --- | --- |
| API | `POST /v1/responses` |
| `temperature` | 0.2 |
| `max_output_tokens` | 512 |
| Потоковая передача ответа | Не используется |
| Тайм-аут клиента | 180 секунд |
| Повторные попытки клиента | 0 |
| Число запросов на задание | 1 |

Время измеряется через `perf_counter()` непосредственно вокруг вызова API и охватывает ожидание полного ответа. Время загрузки модели и прогрев в эту величину не входят. Сокращенный фрагмент измерения:

```python
start = perf_counter()
response = client.responses.create(
    model=model,
    instructions=SYSTEM_PROMPT,
    input=task["prompt"],
    temperature=0.2,
    max_output_tokens=512,
)
elapsed_seconds = perf_counter() - start
```

Для каждого задания скрипт сохраняет JSON-файл: запрос, системную инструкцию, параметры генерации, идентификатор модели, ответ, время, статус и доступную статистику использования токенов. Результаты двух запусков сохранены в отдельных каталогах:

- Qwen: `results/20261105_002221_580787/`.
- Llama: `results/20261105_012402_832802/`.

Оценка выполнялась по содержанию ответа и соблюдению требований запроса. Статус `completed` означает завершение генерации, но не подтверждает правильность ответа. Исходные ответы оценивались без удаления Markdown и исправления ошибок.

### 4.1. Набор запросов

**1. Объяснение понятия из программирования**

```text

```

**2. Написание функции на Python**

```text
напиши функцию sum_even(numbers) на Python, которая возвращает сумму четных целых чисел из списка. для пустого списка верни 0. ответ должен содержать только код функции без Markdown.
```

**3. Поиск ошибки в готовом коде**

```text
найди ошибку в коде. он должен возвращать сумму всех чисел списка. кратко объясни ошибку и приведи исправленный код.

def total(numbers):
    result = 0
    for n in numbers:
        result += n
        return result
```

**4. Извлечение информации в JSON**

```text

текст: Анне 22 года. она живет в Казани.
```

**5. Вопрос без ответа в предоставленном тексте**

```text
ответь только по предоставленному тексту. если информации недостаточно, сообщи об этом.

текст: библиотека работает с понедельника по пятницу с 09:00 до 18:00. по субботам и воскресеньям она закрыта.

вопрос: сколько стоит годовой абонемент в библиотеку?
```

### 4.3. Корректность и соблюдение формата

| Задание | Qwen2.5-1.5B-Instruct | Llama-3.2-1B-Instruct |
| --- | --- | --- |
| Объяснение списка | Правильно описала изменяемую последовательность и дала пример. Нарушила ограничение в два предложения, добавив пояснение после примера. | Ошибочно сравнила список со словарем. Превысила два предложения и добавила английское слово `easily`. |
| Функция `sum_even` | Код корректен для списка целых чисел, включая пустой список. Добавлены запрещенные Markdown-ограждения. | Код корректен для списка целых чисел, включая пустой список. Добавлены запрещенные Markdown-ограждения. |
| Поиск ошибки | Перенесла `return` за пределы цикла, исправив код. Объяснение неверное: модель утверждала, что исходная функция печатает результат, хотя вызова `print` в ней нет. | Выдумала проблему с числами от 10 и переполнением. Добавила к таким числам единицу, из-за чего исправленный код вычисляет неверную сумму. |
| Извлечение JSON | Значения и тип `age` правильные. JSON помещен в Markdown-блок, поэтому весь ответ не является чистым JSON. | Значения и тип `age` правильные. JSON помещен в Markdown-блок, поэтому весь ответ не является чистым JSON. |
| Недостаток информации | Сообщила, что стоимости в тексте нет. В слове «годового» допущена опечатка: «годанкого». | Выдумала стоимость: «0 долларов США», хотя текст цены не содержит. |

В задании с поиском ошибки правильная причина — расположение `return` внутри цикла: функция завершает работу уже после первого элемента, а для пустого списка не возвращает числовую сумму. Правильный вариант:

```python
def total(numbers):
    result = 0
    for n in numbers:
        result += n
    return result
```

В ответе Llama к каждому числу `n >= 10` прибавлялась единица. Например, для списка `[10]` такой алгоритм возвращает `11` вместо `10`. Это показывает, что внешний вид исправленного кода не гарантирует его корректность.

В задании с извлечением обе модели вернули правильное содержимое:

```json
{"name": "Анна", "age": 22, "city": "Казань"}
```

Однако исходные ответы также содержали тройные обратные кавычки. При передаче всего такого ответа непосредственно в `json.loads()` разбор завершится ошибкой. Поэтому правильность данных и соблюдение формата оценивались отдельно.

В целом Qwen лучше справилась с содержанием русскоязычных заданий. При этом ни одна модель не выполнила все требования ко всем пяти ответам.

## 5. Исследование влияния температуры

```text
придумай три разных названия приложения для планирования учебы. для каждого добавь пояснение не длиннее пяти слов. ответь на русском языке ровно тремя пронумерованными пунктами. не добавляй вступление и заключение.
```

Модель, запрос и остальные параметры сохранялись; между ответами история не передавалась. Порядок запусков чередовался: `0.2 → 1.0 → 0.2 → 1.0 → 0.2 → 1.0`. Перед экспериментом выполнялся прогрев. Фиксация `seed` в материалах эксперимента не отражена.

Результаты сохранены в `results/temperature_20261105_013108_795580/`. Все шесть ответов завершились со статусом `completed`.

Для подсчета длины пояснения слова разделялись пробелами; название не учитывалось. Например, при `0.2` в первой попытке последнее пояснение было следующим:

> приложение для планирования учебной деятельности студентов.

Оно содержит шесть слов и нарушает заданное ограничение. При `1.0` в третьей попытке ответ был короче, но два названия остались без пояснений:

```text
1. Уроки онлайн: система быстрой учебы
2. План-контроль SMART
3. Курс готовности к экзаменам
```

| Показатель | Температура 0.2 | Температура 1.0 |
| --- | ---: | ---: |
| Среднее время полного ответа | 5,583 с | 6,803 с |
| Ответы ровно из трех пронумерованных пунктов | 3 из 3 | 3 из 3 |
| Ответы без вступления и заключения | 3 из 3 | 3 из 3 |
| Ответы без выявленного смешения языков | 2 из 3 | 1 из 3 |
| Ответы с соблюдением всех требований | 0 из 3 | 0 из 3 |

Названия менялись даже при температуре `0.2`, поэтому низкая температура не обеспечила одинаковые ответы. При `1.0` в этой серии сильнее менялись длина, структура пояснений и выбор слов; встречалось смешение языков и более странные формулировки. При `0.2` ответы чаще сохраняли короткую форму «название - пояснение», но ограничение в пять слов все равно нарушалось.

Повышение температуры в данном опыте не улучшило соблюдение инструкции. Среднее время при `1.0` оказалось больше, однако отдельный ответ при этой температуре был самым быстрым. Делать вывод о прямой зависимости времени от температуры нельзя: ответы различались по длине, а на каждое значение выполнено только три запуска.

## 6. Ограничения эксперимента

1. На каждое из пяти основных заданий выполнено по одному запросу к каждой модели. Результаты показывают поведение в этих запусках, но не дают статистически устойчивой оценки качества.
2. Сравнение охватывает только две небольшие модели в варианте Q4_K_M и короткие русскоязычные задания. Другие квантования, большие модели и длинный контекст не проверялись.
3. Оценивалось время получения полного ответа. Скорость в токенах в секунду и пиковое потребление RAM/VRAM в сравнительные таблицы не включались.
4. Полные характеристики компьютера и отдельный снимок настроек загрузки Llama отсутствуют, поэтому строгое равенство всех условий запуска не подтверждено.
5. Формат оценивался по исходным ответам. Удаление Markdown могло бы сделать ответы пригодными для обработки, но в этом эксперименте такое исправление не засчитывалось как выполнение инструкции моделью.
6. Для генерации кода требуется отдельная проверка: Qwen исправила код с неверным объяснением, а Llama добавила новую логическую ошибку.

## 7. Вывод

В ходе работы были выбраны и запущены две локальные языковые модели: Qwen2.5-1.5B-Instruct и Llama-3.2-1B-Instruct с квантованием Q4_K_M. Проверена работа чата LM Studio и локального API, выполнены одинаковые задания и отдельный эксперимент с температурой.

**Для проверенных задач на данном компьютере предпочтительнее Qwen2.5-1.5B-Instruct.** Она правильно объяснила понятие списка, сгенерировала работоспособную функцию, исправила положение `return`, извлекла данные из текста и не стала придумывать отсутствующую цену. Среднее время ответа составило 6,070 с против 6,322 с у Llama. Разница во времени невелика; главным основанием выбора стало качество содержания.

Llama занимает меньше места на диске и быстрее ответила на часть запросов, однако допустила существенные ошибки: смешала список со словарем, неверно исправила функцию и выдумала стоимость абонемента. Qwen также требует проверки: ее объяснение ошибки было неверным, а требования к числу предложений, чистому коду и чистому JSON выполнялись не всегда.

В эксперименте с температурой значение `0.2` дало более сдержанные ответы, но не гарантировало соблюдение формата. При `1.0` появились дополнительные языковые и смысловые отклонения. Для задач с жестким форматом следует проверять результат программно, а ответы с кодом анализировать и тестировать перед использованием.
