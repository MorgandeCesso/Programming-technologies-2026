# Отчёт по лабораторной работе №0

## 1. Цель работы

Написать консольного бота, который отправляет запросы модели, меняет системный промпт во время диалога и учитывает последние реплики. Проверить на двух моделях, как меняются ответы при разных значениях температуры и уровнях рассуждения.

## 2. Запуск

 Для первой настройки нужны Python и пакеты из `requirements.txt`.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
if (!(Test-Path .env)) { Copy-Item .env.example .env }
```

**Gemini.** В `.env` нужно указать `GEMINI_API_KEY`. По умолчанию бот использует `gemini-3.1-flash-lite`. 

```powershell
.\.venv\Scripts\python.exe main.py gemini
```

**Qwen.** Для локального запуска использовались llama.cpp b12241 и Qwen3-0.6B в формате GGUF Q4_0. Нужно распаковать архив Windows x64 CPU в папку `.llama` внутри `lab0` и положить файл модели рядом с `llama-server.exe`. [Архив llama.cpp](https://github.com/ggml-org/llama.cpp/releases/tag/b12241), [файл модели](https://huggingface.co/ggml-org/Qwen3-0.6B-GGUF/blob/main/Qwen3-0.6B-Q4_0.gguf)

В первом терминале запустить сервер и оставить его открытым.

```powershell
.\.llama\llama-server.exe -m .\.llama\Qwen3-0.6B-Q4_0.gguf --alias qwen3-0.6b --host 127.0.0.1 --port 8080 -c 4096 -t 8 --parallel 1
```

Во втором терминале запустить бота. Для этого режима ключ не нужен.

```powershell
.\.venv\Scripts\python.exe main.py local
```

## 3. Как работает программа

Весь код находится в `main.py`. В цикле бот читает строку и либо выполняет команду, либо отправляет вопрос. У Qwen запрос идёт через `client.responses.create()`. Промпт передаётся в `instructions`, а реплики в `input`. Gemini использует `client.chat.completions.create()`, где промпт добавляется сообщением с ролью `system`. Бот показывает ответ и время запроса. [Responses API в llama.cpp](https://github.com/ggml-org/llama.cpp/tree/b12241/tools/server#post-v1responses-openai-compatible-responses-api), [совместимый API Gemini](https://aistudio.google.com/docs/openai)

- `/save` сохраняет и включает промпт. `/prompt` показывает список, `/prompt ID` выбирает запись, `/prompt 0` возвращает `SYSTEM_PROMPT` из `.env`. SQLite хранит записи в `prompts.db`.
- `/temperature` принимает число от 0 до 2. `/effort` меняет уровень рассуждения. У Gemini доступны `minimal`, `low`, `medium`, `high`. У Qwen проверялись выключенный режим `none` и включённый `on`.
- После ответа в истории остаётся до трёх пар вопрос–ответ. В следующий запрос входят две последние пары и новый вопрос. После `/clear` запрос начинается с одной реплики. `exit` завершает программу.

## 4. Результаты опытов

В обоих режимах использовались одинаковые вопросы и начальный промпт «Отвечай кратко на русском языке». Перед независимыми запросами история очищалась. Время измерялось от отправки запроса до получения ответа.

### Смена промпта и история

| Проверка                                                                 | Gemini 3.1 Flash-Lite                                                                                                            | Qwen3-0.6B                                                                                                                                                         |
| -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Вопрос «Что такое стек в программировании?» | Объяснила принцип LIFO. После `/save` добавила пример со стопкой тарелок.   | После смены промпта начала ответ словом «Пример», но пропустила аналогию с тарелками.      |
| `/prompt 0`, `/prompt 1` и перезапуск                             | Переключение сработало, после перезапуска промпт «Стек» был в списке. | Переключение сработало, после перезапуска промпт «Стек» был в списке.                                   |
| Запомнить код МАЯК-731 и спросить его                | Вернула «МАЯК-731». После `/clear` ответила «Не знаю».                                       | Получила предыдущие сообщения, но код не назвала. После `/clear` повторила условие вопроса. |

Для Qwen отдельно проверил простой пример на английском. После сообщения «My favorite color is blue» модель назвала синий цвет. Когда предыдущие реплики убрали из запроса, она назвала зелёный. В коде также проверил количество реплик в пяти последовательных запросах. Получилось 1, 3, 5, 5 и снова 1 после `/clear`.

### Температура

Просил придумать три коротких названия для приложения электронной очереди и перечислить их через запятую. Для каждой температуры отправил вопрос три раза. Уровень рассуждения в пределах серии был постоянным — `minimal` у Gemini и `none` у Qwen.

| Температура | Gemini 3.1 Flash-Lite                                                                                                          | Qwen3-0.6B                                                                                                                                                                                                                        |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0,2                    | Все три раза предложила «Очередь», «Слот» и «Поток». Менялся порядок. | Два ответа совпали. Модель повторяла «Очереди электронная» даже внутри одного ответа.                                                                    |
| 1,2                    | В одном из трёх ответов вместо «Поток» появилась «Точка».                      | Все три ответа различались. Среди вариантов были «Европа» и «Очередь для встреч». В одном ответе было только одно название. |

При 1,2 в этой серии появилось больше вариантов. У Qwen среди новых вариантов появились названия, слабо связанные с электронной очередью.

### Рассуждение

Вопрос был один и тот же — сколько пятизначных чисел делятся на 5 и содержат ровно две цифры 7. Температура была равна 1,0. Правильный ответ `918` проверил перебором чисел от 10000 до 99999 в Python.

| Модель | Режим  | Результат                                                                                                                   | Время, с |
| ------------ | ----------- | ------------------------------------------------------------------------------------------------------------------------------------ | -------------: |
| Gemini       | `minimal` | 4092 в начале ответа, расчёт противоречивый.                                                        |           6,00 |
| Gemini       | `low`     | 2364. Ответ неверный.                                                                                                   |           4,30 |
| Gemini       | `medium`  | 918. Ответ и расчёт верные.                                                                                        |           4,72 |
| Gemini       | `high`    | 918. Ответ и расчёт верные.                                                                                        |          28,22 |
| Qwen         | `none`    | Привела шестизначное число 770005. Ответ неверный.                                              |           0,98 |
| Qwen         | `on`      | В итоговом прогоне не вернула текст ответа. В пробном прогоне ответила 8. |             — |

На коротком вопросе «2 + 2» Qwen дала правильный ответ в обоих режимах. При включённом мышлении сервер вернул элемент `reasoning` вместе с сообщением. Измерения времени относятся к этим запросам. Время облачного вызова также зависит от сети.

## 5. Вывод

В обоих режимах бот отправляет запросы, переключает сохранённые промпты и передаёт историю. Gemini лучше выполнила инструкции на русском и вспомнила код из диалога. Qwen запустилась локально без ключа и позволила проверить Responses API, хотя хуже справилась с задачей на подсчёт и с точным форматом ответа.
