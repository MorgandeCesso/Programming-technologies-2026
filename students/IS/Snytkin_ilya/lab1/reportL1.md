## 1. Цель работы

Запустить две модели в LM Studio на своём компьютере, отправить одинаковые запросы через локальный API и сравнить качество, формат и время ответа. Отдельно проверить, как температура влияет на одну из моделей.

### Формат GGUF и обозначение Q4_K_M

**GGUF** — формат файла, в котором хранятся веса модели и данные для её загрузки. **Квантование** уменьшает точность хранения весов, чтобы модель занимала меньше места. Число параметров при этом сохраняется. [Спецификация GGUF](https://github.com/ggml-org/ggml/blob/master/docs/gguf.md).

- **`Q4`** — базовая точность 4 бита. В таком виде хранится основная часть весов.
- **`K`** — семейство схем **K-quants**. Веса кодируются блоками, и для каждого блока сохраняются данные для приближённого восстановления значений.
- **`M`** — *Medium*, средний вариант. Часть весов хранится с большей точностью, чтобы уменьшить потери качества. Поэтому файл обычно чуть больше, чем у варианта `Q4_K_S` (*Small*). [Реализация квантования в llama.cpp](https://github.com/ggml-org/llama.cpp/blob/master/src/llama-quant.cpp).

Например, 3,09 млрд параметров при 16 битах на параметр занимали бы около 6,2 ГБ. Скачанный файл 3B в `Q4_K_M` занимает 2,10 ГБ. При запуске нужна дополнительная память на контекст и работу программы.

## 3. Запуск LM Studio

Для замеров подключён каталог `lab1/models`. Сервер запущен на `127.0.0.1:1234`. Обе модели загружались по очереди с `GPU Offload = 0`. API подтвердил одинаковый контекст 2048 токенов, один параллельный запрос и включённый Flash Attention. Замеры времени проводились до включения обязательной аутентификации.

После замеров включена **Require Authentication**. Запрос `GET /v1/models` без токена получил HTTP 401, а с токеном — HTTP 200 и список моделей. Запрос с токеном к `POST /v1/responses` также получил HTTP 200. Модель Qwen2.5-3B-Instruct ответила `4` на вопрос «Сколько будет 2 + 2?».

1. Установить **LM Studio для Windows x64** и открыть приложение. Если вкладка **Developer** скрыта, включить режим разработчика в **Settings → Developer**. [Скачать LM Studio](https://lmstudio.ai/download?os=windows), [режим разработчика](https://lmstudio.ai/docs/app/user-interface/modes).
2. В **My Models → Models Directory** указать папку `C:\Users\админ\Programming-technologies-2026\students\IS\Snytkin_ilya\lab1\models`. Файлы должны лежать в подпапках `Qwen\Qwen2.5-1.5B-Instruct-GGUF` и `Qwen\Qwen2.5-3B-Instruct-GGUF`. Если на другом компьютере папки пусты, можно скачать нужные варианты через **Discover** по именам репозиториев из ссылок выше. [Структура папок для моделей](https://lmstudio.ai/docs/app/advanced/import-model).
3. В **Developer → Server Settings** выставить порт `1234` и включить **Require Authentication**. В **Manage Tokens → Create Token** создать токен для чтения списка моделей и генерации ответов. Скопировать его в `.env` после `LM_STUDIO_API_TOKEN=`, затем запустить локальный сервер кнопкой **Start Server**. Если `.env` отсутствует, сначала скопировать `.env.example` под этим именем. Токен сохраняется в файле, исключённом из Git. [Аутентификация LM Studio](https://lmstudio.ai/docs/developer/core/authentication).
4. Загрузить модели по очереди с одинаковыми настройками. Команды ниже задают идентификаторы `lab1-qwen-1.5b` и `lab1-qwen-3b` и выгружают первую модель перед загрузкой второй. [Загрузка модели и параметры](https://lmstudio.ai/docs/cli/local-models/load).

Из папки `lab1` в PowerShell выполнить команды ниже. Если окружение ещё не создано, выполнить сначала `python -m venv .venv` и `.\.venv\Scripts\python.exe -m pip install -r requirements.txt`.

```powershell
$lms = Join-Path $env:USERPROFILE '.lmstudio\bin\lms.exe'
& $lms load 'qwen2.5-1.5b-instruct' --gpu off --context-length 2048 --parallel 1 --identifier 'lab1-qwen-1.5b'
.\.venv\Scripts\python.exe experiment.py --list
.\.venv\Scripts\python.exe experiment.py --model 'lab1-qwen-1.5b' --output results/qwen-1.5b.json
.\.venv\Scripts\python.exe experiment.py --model 'lab1-qwen-1.5b' --temperature-test --output results/temperature.json
& $lms unload 'lab1-qwen-1.5b'
& $lms load 'qwen2.5-3b-instruct' --gpu off --context-length 2048 --parallel 1 --identifier 'lab1-qwen-3b'
.\.venv\Scripts\python.exe experiment.py --model 'lab1-qwen-3b' --output results/qwen-3b.json
& $lms unload 'lab1-qwen-3b'
```

## 4. Запросы и критерии проверки

Клиент сначала обращается к `GET /v1/models`, а для генерации использует `POST /v1/responses`. Полный текст каждого запроса находится в [experiment.py](experiment.py). Перед серией идёт короткий прогрев. Замер начинается перед отправкой запроса и заканчивается после получения полного ответа. Скрипт сохраняет ответы, время, температуру и количество выходных токенов, если сервер его вернул. [Responses API LM Studio](https://lmstudio.ai/docs/developer/openai-compat/responses).

| Запрос                                                                      | Что считать правильным                                                                                                 | Требование к формату                                                                                  |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| Объяснить стек                                                       | Объяснён LIFO, приведён подходящий пример                                                                  | Ровно два предложения на русском                                                            |
| Написать `sum_positive`                                                 | Суммируются только числа больше нуля. Пустой список даёт 0                                 | Только код Python                                                                                              |
| Исправить `IndexError`                                                 | Цикл доходит до недопустимого индекса `len(numbers)`. Исправление — `range(len(numbers))` | Две строки с причиной и исправлением                                                     |
| Извлечь данные из объявления                             | Название «Основы Python», кабинет 204, начало 14:30, 12 участников                                  | Один объект JSON с четырьмя заданными ключами и правильными типами |
| Назвать преподавателя по тому же объявлению | Модель сообщает, что информации недостаточно                                                        | Одно предложение без выдуманного имени                                                |

Для основного сравнения температура равна `0.2`, `top_p` равен `1.0`, лимит ответа — 256 токенов. Запросы независимы. В опыте с температурой на 1.5B повторяется вопрос про стек. Скрипт чередует `0.2` и `1.0`, по три запроса при каждом значении, сохраняя остальные параметры. Сравниваются примеры, соблюдение формата и ошибки в объяснении LIFO.

В вопросе про стек 3B дала 59 токенов за 5,398 с, а 1.5B — 143 токена за 6,798 с.

При обеих температурах модель привела по три разных примера, и во всех ответах пример или объяснение содержали ошибку. При 1.0 в одном ответе модель одновременно назвала первым удаляемым и первый, и последний добавленный элемент. При 0.2 она, например, описала удаление старых сообщений снизу, хотя у стека добавление и удаление идут с одной стороны. В этой серии формулировки и примеры менялись при обоих значениях, а число ошибок и соблюдение формата совпали. Три ответа на каждую температуру дают представление только об этом запросе.

## 6. Вывод

Для проверенных задач на этом ПК я бы выбрал **Qwen2.5-3B-Instruct**. Она уложилась в возможности компьютера и дала более надёжный результат там, где важны объяснение ошибки и JSON для программы. **1.5B** завершила набор примерно на 5,6 секунды быстрее и подходит для коротких запросов, где важнее время ответа. Обе модели добавили Markdown вокруг функции и ошиблись с бытовым примером стека. Для программной обработки ответов нужен контроль формата, а вывод о качестве ограничен пятью запросами.
